diffs. This file is generated by the same script.

semantics the wrappers rely on.

## How ApiDocs is captured

ApiDocs is a React app that embeds Swagger UI. Its JavaScript bundle holds a table of
API products, each an OpenAPI file (version 3.0.1 as fetched) under
`https://comtradeapi.un.org/files/v1/app/apim/` with the subscription tiers that may
see it. The page loads only the products of the viewer's tier (anonymous, free or
premium) and merges them client-side into one document, "UN Comtrade API Products",
with one collapsible Swagger UI tag per product, paths prefixed with the product's
server path and operationIds with its key. The script reads the product table from
the bundle and saves every product file byte for byte as served, so the snapshot
holds every product, including the premium ones a free-tier browser never shows.

Help Center articles come from the WordPress REST API,
`https://uncomtrade.org/wp-json/wp/v2/docs?slug=<slug>`, as the article body only
(no theme, no navigation), converted to Markdown. A table with merged cells
(`rowspan`/`colspan`) stays an HTML table that keeps only the spans and links, with
images as their alt text or file name, and the article's row says so; every other
table becomes a pipe table.

Regenerate: `uv run scripts/refresh_upstream.py`

## Files and pages

Fetched is the UTC time the run started, in ISO 8601 with an explicit Z, the same for
every row. HTTP, Bytes and sha256 are those of the body as fetched: for a Help Center
article the REST API's JSON, whose `content` the Markdown file is converted from, the
article's WordPress `modified` field (site time) being in its note. ETag is as sent,
Last-Modified the HTTP header in UTC, `-` where not sent; a body that changes on every
request records none of the four, and its note says why. A page read without a file is
`(no file)`. Requests go one at a time, 2 s apart, each retried at most once after a
network error or a 5xx, identified as `xippios-comtrade refresh_upstream
(+https://github.com/xippios/sdk-comtrade)`; no API key is sent or read.

## Publication Notes

The publication notes page provides explanatory notes for each published dataset. It includes information on the conversion factors, trade system, reported classification, and data sources, among others.

## Decennial Survey

The decennial survey can be accessed at <https://comtrade.un.org/survey/Reports/>. This external site captures the detailed reference and structural metadata on International Merchandise Trade Statistics.

## Reference Tables

You can view and download the code and reference lists used in the UN Comtrade database.

## Correlation Tables

This provides a link to the resources related to [classifications in economic statistics](https://unstats.un.org/unsd/classifications/Econ).
